Icons inside the field

An icon inside the control, at the inline start or end. start and end rather than left and right, because the position is set with inset-inline-* — in an RTL locale a startIcon renders on the right and the name stays true. Give the adornment an onClick and it becomes a real <button type="button">; the type then requires a label, because a button with no accessible name is unusable by anyone not looking at it. Without onClick the icon is decorative and transparent to clicks, so tapping the currency symbol puts the caret in the field behind it.

The compound API, when layout needs controlling

The same parts the convenience component is built from. Reach for these when the order or the markup between them has to change. Field.Root invalid is the one route to an invalid state without a message — and it makes you render your own Field.Error, which is why the convenience component does not expose invalid at all.

Uncontrolled, so it submits before hydration

The value lives in the DOM, not in React state. That is what lets a real form post run its server action before any JavaScript has loaded — the claim test:hydration proves in a browser with every client bundle blocked. Type into this one and submit it: it navigates, because it is a real form.
