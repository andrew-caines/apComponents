# Theme generator

Pick a brand colour. Everything below is generated by the same engine your build uses.

{/* Docs pages get no story decorators, so no ApProvider; Select needs a LocaleProvider. */}
<LocaleProvider>
  <ThemeGenerator />
</LocaleProvider>

[Theming](?path=/docs/foundations-theming--docs) covers both ways to ship the
result: the build-time stylesheet, which costs nothing at runtime, and the runtime
path, which passes the theme to `ThemeProvider`. A `?brand=` value in the address
bar, such as `?brand=c2185b`, sets the starting colour.

The downloaded `theme.css` is a drop-in replacement for `@ap/react/theme.css`.
Both come from the same generator, `toCssText`, and both declare the same
`@layer` order. Import it in place of `@ap/react/theme.css`, and keep importing
`@ap/react/fonts.css` and `@ap/react/motion.css`.
