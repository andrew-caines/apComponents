# Colour

Semantic colour roles in both schemes — every pairing CI checks for contrast.

Every pairing here is checked for contrast in CI (gate 2) in both schemes. Use
the toolbar's theme control to switch between them.

## Status tones

Each tone carries a solid, a subtle background, a border, a text colour and an
on-solid foreground — so a component never has to pick a shade. The four
status tones carry this full set. `action` deliberately has no border token —
it is an interaction colour, not a status, and nothing in the library draws an
"action border" — which is why it is shown separately above rather than
folded into this loop, so the gap is visible rather than hidden behind a
fallback.

<div className="stack">
  {['danger', 'warning', 'success', 'info'].map((tone) => (
    <div key={tone} className="row">
      <span className="mono">{tone}</span>
      <div
        style={{
          padding: 'var(--ap-space-2) var(--ap-space-4)',
          borderRadius: vars.radius.sm,
          background: vars.color[`${tone}Bg`],
          color: vars.color[`${tone}OnSolid`],
        }}
      >
        on solid
      </div>
      <div
        style={{
          padding: 'var(--ap-space-2) var(--ap-space-4)',
          borderRadius: vars.radius.sm,
          background: vars.color[`${tone}BgSubtle`],
          color: vars.color[`${tone}Text`],
          border: `1px solid ${vars.color[`${tone}Border`]}`,
        }}
      >
        subtle
      </div>
    </div>
  ))}
</div>
